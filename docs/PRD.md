# Product Requirements Document: Loop

## 1. Продукт и ЦА

**Loop** — приложение для пар (18–35 лет), помогающее поддерживать близкие отношения через ежедневные практики, инсайты и доступ к ИИ-психологу.

**Целевая аудитория:**
- Пары, желающие улучшать отношения
- Интересуемые астрологией и совместимостью
- Пары на расстоянии или с занятым расписанием

**Метрики:**
- DAU / MAU
- удержание D7, D30
- длина streak (серии ежедневных действий)
- конверсия от инвайта к первому свиданию
- удержание после первого чат-сеанса с ИИ

## 2. Проблема и решение

**Проблема:**
- Пары теряют контакт из-за занятости, конфликтов, эмоционального выгорания
- Нет простого способа отслеживать отношения и получать инсайты
- ИИ-психологи доступны но дорого и не помнят контекст пары

**Решение:**
- Ежедневные «мини-практики» (1–3 минуты)
- Автоматический трекинг «пульса» отношений (мотивация, конструктивность конфликтов)
- Интеллектуальные челленджи на основе данных
- ИИ-психолог с долгой памятью о паре
- Визуализация динамики через стрик и графики

## 3. ИА (Информационная архитектура)

### 4 таба интерфейса:
1. **Дом** — центр дня, стрик, вопрос дня, быстрые действия
2. **Пара** — паспорт, отчёт, тесты, синастрия
3. **Свидание** — инвайты, база мест, история
4. **Психолог** — Сова: соло + режим «Вместе», история диалогов

### Правило дизайна:
«Один экран — одна задача». Все действия инлайн, без лишних перебросов на другие страницы.

## 4. MoSCoW 우선순위 фичи

### Must (в splash-версии):
- Ежедневный вопрос/스틱р
- Базовые тесты (привязанность, языки любви)
- Инвайт на свидание
- Соло-режим психолога

### Should:
- Режим «Вместе» в чате с ИИ
- Синнастрия-отчёт
- Настройка тем (Aurora/Night)
- Push-уведомления

### Could:
- Астрологический отчёт (синастрия)
- Нативные приложения iOS/Android
- Монетизация (премиум-фичи)
- Интеграция с календарем

### Won't (на старте):
- Видео-сессии с психологом
- Публичный профиль без привязки пары
- Кросс-платформенный чат (только внутри Loop)

## 4. Нефункциональные требования

### Приватность (Solo-chat principle):
- Соло-чат с ИИ изолирован от данных пары по умолчанию
- Данные пары не передаются третьим лицам
- GDPR / 152-ФЗ compliance: экспорт данных, удаление аккаунта при 요청

### Доступность (a11y):
- Контрастность цветов (Aurora/Dark темы)
- Touch-target минимум 44px
- Навигация клавиатурой
- Поддержка экранного читателя

### Производительность:
- Первая загрузка < 2 сек (Turbopack)
- Push-уведомления < 200мс задержки
- Офлайн-режим: просмотр Already-seen данных

### Масштабируемость:
- Next.js 14 App Router с ISR для статических данных
- Prisma с Neon Serverless PostgreSQL
- Upstash Redis для кэша сессий и стриков
